# DOCTRINE · 三纲五常

> ContextOS 的核心理念。所有代码、文档、门禁、对话都必须能对回这里。
> 与 `RSI-CONSTITUTION.md` 的关系：三纲五常是**方向**，RSI 七条是**每轮的判据**。

---

## 一、三纲

| 纲 | 做什么 | 达成什么 |
|---|---|---|
| **集群化部署** | 一台机器起节点，节点起空间，空间起应用；节点之间可互连、可远程执行命令 | **所有设备互联互通** |
| **模块化开发** | 应用 = 模板 + 模块 + 功能；功能按框架规范生成，不手写重复结构 | **所有代码自动生成** |
| **自动化应用** | 应用实例、数据、权限、接口由命令与门户统一承载 | **所有数据自由流动** |

三纲是**结构**：集群是骨、模块是肉、数据是血。

---

## 二、五常

| 常 | 落点 | 当前载体 |
|---|---|---|
| **代码** | 能跑、能被生成、能被门禁约束 | `src/`、`lib/`、`src/template/` |
| **文档** | 说清形状与边界，供人与 AI 共读 | `docs/*`、`AGENTS.md` |
| **会话** | 人与 AI 的协作过程，可回溯、可沉淀 | 插件内对话、`dsh-reports/` |
| **团队** | 角色、权限、分工（visitor/creator/leader/worker/tech） | `member/apply/allow`、`role`、`IsLeader` |
| **市场** | 应用模板与服务的流通、上架、交易 | `service`、`store`、`fund/market/credit` |

五常是**内容**：代码与文档是产品，会话是过程，团队是组织，市场是出口。

---

## 三、工作模式：AI 对话驱动

```
一次对话
  → 产出代码（能跑）
  → 产出文档（说清）
  → 产出/加固门禁（防回归）
  → 产出/更新规范（可复用）
  → 下一轮更快
```

**每轮收尾四件套（缺一视为未完成）**

| 件 | 判据 |
|---|---|
| 代码 | `npm run build:client` 全绿；接口回执可验证 |
| 文档 | 与改动同一次提交更新对应 `docs/*` |
| 门禁 | 本轮踩过的坑 → 新增一条 `gate.mjs` / `ui-check.mjs` / `context-check.mjs` 断言 |
| 规范 | 规则写进 `AGENTS.md` 或 `docs/CODE-GEN.md`，而不是留在对话里 |

---

## 四、抽象递减

目标不是「写得更多」，而是**同样功能越写越少**：

```
第一次：手写 300 行
第二次：模板生成 120 行
第三次：词表 + 参数文法 30 行
第四次：一句提示词 + 确认表单 → 0 行手写
```

每轮必须做一次抽象动作（任选其一）：

- 把重复代码抽成模板（`lib/core/codegen.js`）
- 把重复判断抽成词表（`lib/core/vocab.js`）
- 把重复调用抽成工具/脚本（插件 op、DSH 工具）
- 把重复约定抽成门禁断言

**度量**

| 指标 | 方向 |
|---|---|
| 单功能手写行数 | 下降 |
| 模板/词表覆盖的功能数 | 上升 |
| 门禁断言数 | 上升（只增不删） |
| 同类问题复发次数 | 归零 |

---

## 五、约束：用框架、模板、规范、门禁管住 AI

| 约束 | 手段 | 违反后果 |
|---|---|---|
| 框架 | `ice.Hash` / `db.Table` / `Volcanos` / `icebergs` | 编译失败或运行时错 |
| 模板 | `codegen.js` 的模板与 `moduleSkeleton` | 生成被拒 |
| 规范 | `AGENTS.md`、`CODE-GEN.md`、`URL-SPEC.md`、`INTERFACE.md` | `gate` / `context-check` 红 |
| 门禁 | `gate.mjs`、`ui-check.mjs`、`ui-verify.mjs`、`context-check.mjs` | 构建失败，不允许交付 |

> 一句话：**不靠自觉，靠跑不起来。**

---

## 六、判据（每轮自检）

1. 这轮解决了哪个纲上的问题？（集群 / 模块 / 数据）
2. 五常里动了哪几常？没动的为什么不动？
3. 四件套齐了吗？（代码 / 文档 / 门禁 / 规范）
4. 抽象动作做了什么？手写行数降了吗？
5. 有没有把结论留在对话里而没落盘？有就是没做完。
